How it works

Three steps, then it runs itself

Connect the repository once. After that Northwind watches every merge and keeps the release train on schedule.

Connect your repo

Sign in with GitHub or GitLab and pick the projects you want on the train. Nothing is written until you approve the first run.

Approve the pipeline

Northwind proposes the checks for your stack: type check, lint, tests, accessibility, bundle budget. Edit anything, then lock it in.

Ship on a schedule

Merges queue up, checks run, and the release promotes itself through canary to production. You get a report, not a fire.

Features

The parts of release engineering nobody wants to build

Checks that match your stack

Northwind reads the repository and configures the pipeline for it: Node, Python, Go, Rust, or a monorepo with all four. Accessibility and bundle budgets are on by default, because that is usually where quality slips first.

Canary by default

Every release starts at 10% of traffic and promotes only when error rates hold.

Reports a human reads

What shipped, what got slower, what needs attention. One page, ordered by impact, delivered where your team already talks.

Rollback in one command

Health checks fail, the previous release is live again before anyone opens a laptop. No backup restores at 2am.

FAQ

Questions worth answering

Do we have to move hosting?

No. Northwind deploys to your existing target: Vercel, Netlify, Fly, AWS, or a server you already run. It orchestrates the release, it does not own your infrastructure.

What happens when a check fails?

The release stops before production. You get the failing check, the diff, and a suggested fix. Nothing ships until it is green or you override with a recorded reason.

Can we keep our current CI?

Yes. Point Northwind at your existing workflow files and it will run them as part of the release train, adding only the gates you choose.

How long does setup take?

Connecting a repository takes a minute. The first full pipeline, including review of the proposed checks, usually takes under half an hour.
