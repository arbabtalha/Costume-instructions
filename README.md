# Costume Instructions

A static web page for reading, copying, and downloading the costume instructions.

Open `index.html` locally to preview it. To publish the site, enable GitHub Pages under **Settings → Pages** using **Deploy from a branch**, select `arena/646500d9-costume-instructions` and `/(root)`, then save. After the Pages build finishes, the public website will be available at:
https://arbabtalha.github.io/Costume-instructions/

The original `Costume instructions.html` is retained for compatibility.
